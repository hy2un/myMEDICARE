# myMEDICARE

프로젝트 소개
My MediCare는 개인의 복용 의약품을 관리하고, 여러 의약품의 성분을 비교하며, 자신의 질병과 증상을 기록할 수 있는 건강정보 통합 웹 애플리케이션입니다. 의약품 정보와 주변 의료기관을 편리하게 확인할 수 있도록 Python과 Streamlit을 활용하여 개발하였습니다.

사용 방법
웹사이트에 접속한 후 메인 화면에서 의약품을 검색하여 나의 약 목록에 추가하거나, 성분 분석에서 여러 의약품을 선택하여 중복 성분을 확인할 수 있습니다. 왼쪽 사이드바를 이용하면 성분 사전, 약 종류, 근처 병원·약국, 동물 건강, 증상 AI 상담 페이지로 이동하여 원하는 정보를 검색하고 확인할 수 있습니다.

주요 기능 설명
의약품 검색과 최대 5개 약물의 성분 비교, 질병·증상 목록 선택 및 관리 기능을 제공합니다. 성분 사전에서는 의약품 성분과 관련 용어의 의미를 확인할 수 있으며, 카카오 지도 API를 이용한 병원·약국 검색과 반려동물 약물 정보 조회도 가능합니다. 또한 Google Gemini API를 활용해 증상과 식단, 의약품 성분에 관한 일반적인 건강정보를 안내합니다.

실행 방법
GitHub에서 프로젝트 파일을 내려받은 후 pip install -r requirements.txt 명령어로 필요한 라이브러리를 설치하고, streamlit run main.py 명령어로 실행합니다. Gemini 및 Kakao API 기능을 이용하려면 Streamlit Secrets에 각각의 API 키를 등록해야 합니다. 배포된 웹사이트는 https://mymedicare.streamlit.app/ 에서 이용할 수 있습니다.
